# Data Collection App

Ứng dụng thu thập dữ liệu ảnh bệnh sầu riêng ngoài thực địa.

## Mục tiêu

- Chụp hoặc tải ảnh lá, thân, trái và vùng nghi nhiễm bệnh.
- Gắn nhãn bệnh, mức độ, vị trí, thời gian và ghi chú hiện trường.
- Xuất hoặc đồng bộ dữ liệu về `ai/data` hoặc `backend` để phục vụ huấn luyện model.

## Thư mục

- `lib/`: mã nguồn ứng dụng.
- `assets/`: ảnh, icon, cấu hình tĩnh và tài nguyên giao diện.
