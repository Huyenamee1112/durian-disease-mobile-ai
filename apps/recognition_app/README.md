# Recognition App

Ứng dụng chính nhận diện bệnh sầu riêng trên thiết bị di động.

## Mục tiêu

- Nhận ảnh từ camera hoặc thư viện ảnh.
- Chạy inference trực tiếp trên thiết bị hoặc gọi API backend.
- Hiển thị bệnh dự đoán, độ tin cậy, vùng nghi nhiễm và khuyến nghị xử lý.
- Kết nối AI Agent để giải thích kết quả và hỗ trợ hỏi đáp.

## Thư mục

- `lib/`: mã nguồn ứng dụng.
- `assets/`: model mobile, ảnh, icon và tài nguyên giao diện.
